# Secure CLI Login System

This repository contains my solution for the **Go Backend Intern technical assignment**.

The task is to build a containerized command-line login system with:

* User registration and authentication
* Secure password hashing
* Session management
* Account lockout after failed login attempts
* Optional TOTP-based two-factor authentication (2FA)
* Persistent database storage
* Dockerized setup

## Tech Stack

* Go
* PostgreSQL
* Docker
* Docker Compose
